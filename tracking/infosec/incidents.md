## Rules for writing in this file

**Never record passwords, IP addresses, server or device names, or member details
here.** This file is published on a public website.

**Never name the person involved.** Describe what happened in plain words instead —
for example "a staff member replied to a scam email" rather than naming anyone.

An empty table means nothing has been recorded, not that nothing happened. If an
incident occurs, write it down here the same month.
