## What each column means

- **ATM cards issued** — new or replacement member cards produced.
- **ATM machine issues** — call-outs where a machine needed attention.
- **Branch maintenance visits** — trips to a branch for scheduled upkeep.
- **Technical requests** — everyday help requests from staff.
- **Average response time** — how long, on average, from a request coming in to
  someone starting work on it.
