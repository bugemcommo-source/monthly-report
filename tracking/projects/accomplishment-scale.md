# Accomplishment Scale — how a system's percentage is set

Chosen by the owner on 9 October 2026 for the system portfolio PDF. Every system's
"Progress" figure is read off this one scale from its recorded stage. It is not a measure
of code written. A system moves up only when its project file records the next stage.

| Stage | Percentage |
|---|---|
| Planning (not yet started) | 10% |
| Building | 40% |
| Built / ready, not yet presented | 60% |
| Presented | 75% |
| Deployed, not yet in use | 90% |
| Live and in use | 100% |
